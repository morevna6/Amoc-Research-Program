## Overview

The **AMOC Research Program** is a long-term independent research initiative dedicated to understanding the Atlantic Meridional Overturning Circulation through scientific literature, authoritative observational datasets, reproducible data analysis, physical reasoning, and careful scientific communication.

This repository is not intended to be a one-time dashboard project or a collection of disconnected analyses.

It is being developed as a **living research record** in which scientific foundations, source decisions, datasets, assumptions, methods, code, limitations, revisions, and conclusions can remain traceable as the programme develops.

The project does **not** begin with the assumption that the AMOC is stable, collapsing, or approaching a predetermined tipping date.

Competing findings and unresolved uncertainties will be documented rather than forced into a single narrative.

## Why This Project Exists

The Atlantic Meridional Overturning Circulation, commonly referred to as the **AMOC**, is a major component of the Earth’s climate system.

It contributes to the redistribution of heat, freshwater, salt, carbon, nutrients, and other ocean properties throughout the Atlantic Ocean. Changes in its strength and structure may influence regional climate, precipitation patterns, dynamic sea level, marine ecosystems, coastal systems, and long-term societal resilience.

Despite its importance, the AMOC remains difficult to observe, reconstruct, and predict.

Continuous basin-wide monitoring at approximately 26.5°N began in 2004 through the RAPID observing system. This record has transformed scientific understanding of short-term and interannual AMOC variability, but it remains short compared with the decadal and multidecadal timescales on which the circulation may vary.

Understanding the AMOC therefore requires the combined use of:

* direct observations;
* hydrographic measurements;
* ocean reanalyses;
* palaeoclimate evidence;
* statistical indicators;
* theoretical models;
* climate-model simulations;
* scenario-dependent projections.

Each type of evidence contains different assumptions, uncertainties, spatial limitations, temporal limitations, and methodological biases.

This project exists to examine those differences through a long-term, modular, transparent, and reproducible research programme.

## Guiding Research Questions

Every module will return to four recurring questions:

1. **What do we currently know?**
2. **How do we know it?**
3. **How certain are we?**
4. **What remains unknown?**

These questions will guide the project from foundational scientific study to literature review, dataset selection, data engineering, exploratory analysis, physical calculation, modelling, interpretation, and communication.

## Core Principles

The programme follows several foundational principles:

* **Evidence before narrative**
* **Research before visualisation**
* **Reproducibility before convenience**
* **Transparent assumptions and limitations**
* **Clear distinction between observations, reconstructions, simulations, and projections**
* **Versioned conclusions that may change when evidence changes**
* **Accessible communication without sacrificing scientific accuracy**
* **Machine learning only where scientifically justified**
* **Uncertainty treated as part of the result**
* **No predetermined conclusion**

The project will not select evidence according to a preferred narrative.

Where findings conflict, disagreement will be documented rather than silently removed.

Where evidence is incomplete, uncertainty will be preserved rather than converted into false precision.

---

## Scientific and Computational Approach

The project connects scientific understanding with computational practice.

Data analysis cannot be scientifically meaningful when detached from the physical system that produced the data.

Before calculating trends, constructing indicators, or applying predictive models, the project will establish foundations in:

* Earth system science;
* climate dynamics;
* oceanography;
* fluid dynamics;
* ocean thermodynamics;
* water-mass formation;
* Atlantic circulation;
* AMOC observation systems;
* uncertainty analysis;
* the historical development of AMOC research.

Every dataset, equation, transformation, visualisation, and model should eventually answer five questions:

1. **What physical quantity does it represent?**
2. **How was it measured, reconstructed, or simulated?**
3. **What assumptions were required?**
4. **What uncertainty and limitations does it contain?**
5. **What conclusions can it legitimately support?**

---

## Research Objective Hierarchy

The programme follows a deliberate research sequence:

> **Understand → Verify → Acquire → Validate → Analyse → Model → Interpret → Communicate → Reassess**

The order is intentional.

Scientific understanding should precede data acquisition.

Validation should precede interpretation.

Modelling should follow a clearly defined scientific question.

Communication should preserve uncertainty discovered during analysis.

Conclusions should remain open to reassessment as evidence develops.

* a finished scientific model.

Such claims may only be considered later if supported by appropriate evidence, methodology, validation, uncertainty assessment, physical interpretation, and comparison with existing scientific literature.

## Scientific Communication Policy

The project will avoid using dramatic language as a substitute for evidence.

It will also avoid using scientific uncertainty as an excuse for indifference.

Scientific caution does not mean that a risk is unimportant. It means that claims must remain proportional to the evidence supporting them.

The project will distinguish carefully among:

* short-term variability;
* long-term weakening;
* resilience loss;
* critical slowing down;
* threshold crossing;
* tipping risk;
* partial circulation reorganisation;
* abrupt transition;
* complete AMOC collapse.

These concepts are related, but they are not interchangeable.

Project progress will not be measured solely by the number of:

* documents;
* datasets;
* notebooks;
* models;
* visualisations;
* publications.

A research stage represents meaningful progress when it improves one or more of the following:

1. **Scientific understanding**
2. **Evidence quality**
3. **Methodological clarity**
4. **Reproducibility**
5. **Uncertainty characterisation**
6. **Physical interpretation**
7. **Documentation**
8. **Accessibility of scientific knowledge**

A technically sophisticated output without adequate scientific justification will not be treated as successful merely because it exists.

## Project Philosophy

This project is not built around the promise of certainty.

It is built around the commitment to investigate uncertainty honestly.

The AMOC is scientifically consequential, globally connected, and incompletely understood. Its importance demands sustained attention, while its uncertainty demands methodological discipline.

This repository documents that investigation from its foundations onward.
