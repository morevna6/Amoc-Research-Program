AMOC Research Program

A scientific, modular, and reproducible investigation of the Atlantic Meridional Overturning Circulation

Project status: ActiveCurrent phase: Phase 0 — Research FrameworkCurrent module: Module 0.1 — Project PhilosophyInitial release: 28 July 2026

Overview

The AMOC Research Program is a long-term independent research initiative dedicated to understanding the Atlantic Meridional Overturning Circulation through scientific literature, authoritative observational datasets, reproducible data analysis, physical reasoning, and careful communication.

This repository is not intended to be a one-time dashboard project or a collection of disconnected analyses. It is being developed as a living research record in which the scientific foundations, source decisions, datasets, assumptions, methods, code, limitations, revisions, and conclusions remain traceable.

The project does not begin with the assumption that the AMOC is stable, collapsing, or approaching a predetermined tipping date. Competing findings and unresolved uncertainties will be documented rather than forced into a single narrative.

First Research Publication

0.1.1 — Why This Project Exists

This foundation paper explains:

why the AMOC warrants a long-term research programme;

why its behaviour cannot be understood from a single dataset or method;

why uncertainty must be treated as a scientific result;

how the project will connect ocean and climate science with reproducible computational research;

why public communication must distinguish weakening, variability, resilience loss, tipping, and collapse.

Research Questions Used Throughout the Project

Every module will return to four questions:

What do we currently know?

How do we know it?

How certain are we?

What remains unknown?

Core Principles

Evidence before narrative

Research before visualisation

Reproducibility before convenience

Transparent assumptions and limitations

Clear distinction between observations, reconstructions, models, and projections

Versioned conclusions that may change when evidence changes

Accessible communication without sacrificing scientific accuracy

Machine learning only where scientifically justified

Project Roadmap

The programme begins with research philosophy and methodology before moving into Earth system science, ocean physics, thermohaline circulation, Atlantic dynamics, AMOC observations, historical development, current scientific understanding, data infrastructure, exploratory analysis, scientific analysis, modelling, interpretation, global impacts, and communication.

Current Boundaries

At this stage, the repository contains the project framework rather than completed scientific analysis.

It does not currently claim:

a new estimate of AMOC strength;

detection of a tipping point;

a forecast of collapse timing;

validation or rejection of a specific published study;

a complete synthesis of the scientific literature;

a production-ready data pipeline.

These claims may only be made later if supported by appropriate evidence and methods.
