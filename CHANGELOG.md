## 16 August 2026

### Added

* `docs/phase-0/module-0.1-project-philosophy/0.1.3-research-objectives.md`

### Updated

* Module 0.1 progress advanced from **2 of 6** to **3 of 6** completed sections.
* The current project milestone was updated to `0.1.3 — Research Objectives`.
* The next planned milestone was set to `0.1.4 — Scope and Limitations`.
* `PROJECT_STATUS.md` was updated to reflect the completion of the third project-philosophy section.
* The repository structure was updated to include the new research-objectives document.

### Research Foundation

The third project-philosophy document formally defined the objectives of the AMOC Research Program across multiple research dimensions.

These include:

* scientific understanding;
* Earth-system and climate foundations;
* physical oceanography;
* AMOC theory;
* literature and evidence evaluation;
* observation-system research;
* dataset provenance and infrastructure;
* data-quality assessment;
* physical and statistical analysis;
* early-warning and tipping-point research;
* computational modelling;
* uncertainty assessment;
* reproducibility;
* physical interpretation;
* impact research;
* education;
* scientific communication;
* open science;
* long-term research development.

### Objective Hierarchy Established

The project introduced the following sequence to guide later scientific and computational work:

> **Understand → Verify → Acquire → Validate → Analyse → Model → Interpret → Communicate → Reassess**

This hierarchy establishes that:

* scientific understanding should precede data acquisition and modelling;
* validation should precede interpretation;
* modelling should follow a clearly defined scientific question;
* communication should preserve uncertainty identified during analysis;
* conclusions should remain open to reassessment as evidence develops.

### Analytical Principles Clarified

The programme established that:

* statistical significance alone is not sufficient for physical interpretation;
* machine learning will be used only where scientifically justified;
* model complexity must provide demonstrable analytical or scientific value;
* early-warning indicators will not automatically be treated as evidence of an approaching physical tipping point;
* detection and attribution will be treated as separate scientific problems;
* exploratory findings will remain distinct from validated project conclusions;
* uncertainty will be integrated throughout the analytical workflow rather than added only at the reporting stage.

### Progress Criteria Introduced

Project progress will not be measured solely through the number of:

* documents;
* datasets;
* notebooks;
* models;
* visualisations;
* publications.

A research stage will instead be considered meaningful when it improves one or more of the following:

1. scientific understanding;
2. evidence quality;
3. methodological clarity;
4. reproducibility;
5. uncertainty characterisation;
6. physical interpretation;
7. documentation;
8. accessibility of scientific knowledge.

### Claim Criteria Introduced

Before a major project-generated conclusion is presented, the programme should be able to identify:

* the supporting evidence;
* how the evidence was produced;
* the analytical method;
* required assumptions;
* methodological sensitivity;
* remaining uncertainty;
* alternative explanations;
* consistency or disagreement with published literature;
* what the result does **not** establish.

Findings that cannot yet satisfy these conditions should remain exploratory.

### Notes

* `0.1.3 — Research Objectives` defines intended future work rather than completed scientific analysis.
* No observational dataset has yet been selected or analysed.
* No project-generated AMOC trend, tipping-point result, model output, or physical interpretation has yet been produced.
* The preliminary reference register remains in place.
* Module 0.1 is now halfway complete.

### Updated

* Module 0.1 progress advanced from **1 of 6** to **2 of 6** completed sections.
* The current project milestone was updated to `0.1.2 — Motivation and Significance`.
* The next planned milestone was set to `0.1.3 — Research Objectives`.
* Sources used in the first two project-foundation documents were consolidated into a preliminary reference register.
* The Module 0.1 directory received an index documenting its objective, structure, progress, and completion conditions.

### Research Foundation

The second project-philosophy document established:

* the scientific motivation for investigating the AMOC;
* its significance within the coupled Earth system;
* its relevance to heat transport, carbon storage, dynamic sea level, and the water cycle;
* the environmental and societal relevance of possible AMOC changes;
* the methodological value of connecting physical understanding with reproducible computational research;
* the role and boundaries of independent research;
* the importance of responsible public communication;
* the distinction between risk relevance and unsupported impact claims.

### Clarified

The project does not currently claim:

* that an AMOC collapse is imminent;
* that a specific tipping threshold has been detected;
* that a reliable collapse date has been calculated;
* that observed changes can be attributed entirely to anthropogenic forcing;
* that a single dataset represents the complete overturning system;
* that broad AMOC changes can be converted directly into specific social or economic outcomes.

### Notes

* The reference register remains preliminary.
* It is not yet the full literature database planned for Module 0.3.
* No observational dataset, analytical pipeline, statistical model, dashboard, or project-generated scientific result has been introduced.
* Phase 0 remains focused on establishing the research framework before scientific analysis begins.

## 28 July 2026

### Added

* Initial public GitHub repository
* `README.md`
* `ROADMAP.md`
* `docs/phase-0/module-0.1-project-philosophy/0.1.1-why-this-project-exists.md`

### Established

* **Phase 0 — Research Framework**
* **Module 0.1 — Project Philosophy**
* The initial structure of the AMOC Research Program
* The project’s long-term, modular, and reproducible research approach
* An evidence-first and uncertainty-aware research posture
* A distinction between scientific findings and project commitments
* A commitment to preserving disagreement and uncertainty rather than manufacturing consensus
* A commitment to connecting data analysis with the physical system that produced the data

### First Publication

The first project-foundation document, `0.1.1 — Why This Project Exists`, defined:

* why the AMOC warrants sustained investigation;
* why observations, reconstructions, simulations, and projections must be distinguished;
* why the programme will not begin with a predetermined conclusion;
* why uncertainty should be treated as part of the scientific result;
* why scientific understanding must precede computational analysis;
* why public communication must distinguish variability, weakening, resilience loss, tipping, and collapse.

### Guiding Questions Introduced

Every research module will return to four recurring questions:

1. **What do we currently know?**
2. **How do we know it?**
3. **How certain are we?**
4. **What remains unknown?**

### Initial Boundaries

At launch, the project contained no:

* original AMOC-strength estimate;
* tipping-point detection;
* collapse forecast;
* dataset analysis;
* physical calculation;
* statistical model;
* machine-learning model;
* dashboard;
* animation;
* project-generated scientific conclusion.
